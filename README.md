# Personal Budget & Expense Tracker — Week 2

## Project overview
This is a static HTML and CSS project for a personal budget and expense tracker. It demonstrates a structured expense form, a table of sample expenses, multimedia content, and basic interactive HTML elements. The form is not connected to JavaScript yet.

## Files
- `index.html` — contains the page structure, expense form, sample expense table, collapsible help section, logo image, and embedded video.
- `style.css` — contains layout, colors, spacing, form and table styling, responsive adjustments, and advanced CSS selectors.

## Features included
- Semantic HTML page structure using `header`, `main`, and `section`.
- Expense form with name, amount, and category fields.
- Category dropdown with Food, Transport, Rent, Entertainment, and Other.
- Add Expense button with `type="button"` (not functional yet).
- Expense table with `thead`, `tbody`, headers, and five sample rows.
- Logo image with `src`, `alt`, and `width` attributes.
- Embedded YouTube iframe with title, width, height, and frameborder attributes.
- Collapsible “How to use this tracker” section using `details` and `summary`.
- CSS hover and focus states, alternating table row colors, and advanced selectors.

## How to run
1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a web browser, or use the Live Server extension in VS Code.

## Note
The expenses shown are hardcoded sample data. The Add Expense button does not add records at this stage. JavaScript functionality will be added in a later week.
